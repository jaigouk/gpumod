*   Implement priority-based job scheduling for a `JobQueue` class.
    *   Requirements:
        1.  `add_job(job_name, data, priority=0)`: Add a job with an optional priority.
        2.  Priority rules: Higher priority first (Critical=2, High=1, Normal=0).
        3.  Tie-breaker: FIFO (First-In, First-Out) for same priority.
        4.  `get_next_job() -> tuple[str, dict] | None`: Get and remove the highest priority job.
    *   Data structure choice: A priority queue (heap) is the standard way to handle priorities efficiently ($O(\log n)$ for insertion and extraction).
    *   Python's `heapq` module implements a min-heap. To make it a max-heap for priorities (where 2 is highest), we can store priorities as negative values (e.g., -2, -1, 0).
    *   To handle FIFO for same priorities, we need a counter (sequence number) to ensure that if priorities are equal, the one added earlier is processed first.

    *   `heapq` for the priority queue.
    *   `dataclass` or `namedtuple` (or just a tuple) to store the job info. Actually, a simple tuple `(-priority, entry_count, job_name, job_data)` works perfectly with `heapq`.

    ```python
    from typing import Tuple, Dict, Optional

    class JobQueue:
        def __init__(self):
            self.queue = []
            self.count = 0

        def add_job(self, job_name: str, data: dict, priority: int = 0):
            # Use negative priority for max-heap behavior
            # Use self.count to maintain FIFO for equal priorities
            heapq.heappush(self.queue, (-priority, self.count, job_name, data))
    ```

```python
import heapq
from typing import Tuple, Dict, Optional

class JobQueue:
    def __init__(self):
        self._queue = []
        self._count = 0

    def add_job(self, job_name: str, data: Dict, priority: int = 0) -> None:
        # heapq is a min-heap. To treat higher numbers as higher priority,
        # we store priority as a negative value.
        # self._count ensures FIFO order for jobs with the same priority.
        heapq.heappush(self._queue, (-priority, self._count, job_name, data))
        self._count += 1

    def get_next_job(self) -> Optional[Tuple[str, Dict]]:
        if not self._queue:
            return None
        
        _, _, job_name, data = heapq.heappop(self._queue)
        return (job_name, data)
```
