This refactor follows the **Single Responsibility Principle**: `core` handles data definitions, `priority` handles ordering logic, `retry` handles timing/failure logic, and `__init__` manages the public API.

### The New Structure

├── __init__.py

### 1. `queue/core.py`
Contains the base data structures and the standard FIFO queue.

```python
from dataclasses import dataclass, field
from typing import Callable, Any
from collections import deque

@dataclass
class Job:
    id: str
    task: Callable[[], Any]
    priority: int = 0
    retries: int = 0
    max_retries: int = 3
    description: str = ""

class JobQueue:
    """A standard First-In-First-Out (FIFO) job queue."""
    def __init__(self):
        self._queue = deque()

    def push(self, job: Job):
        self._queue.append(job)

    def pop(self) -> Job:
        if not self._queue:
            raise IndexError("Queue is empty")
        return self._queue.popleft()

    def __len__(self):
        return len(self._queue)
```

### 2. `queue/retry.py`
 Contains the logic for handling failures and exponential backoff.

```python
import time
import random
from typing import Callable
from .core import Job

def calculate_backoff(retry_count: int) -> float:
    """Calculates exponential backoff with jitter."""
    base_delay = 2 ** retry_count
    jitter = random.uniform(0, 1)
    return base_delay + jitter

def process_with_retry(job: Job) -> Any:
    """
    Executes a job with exponential backoff logic.
    Returns the result of the task or raises an exception.
    """
    while job.retries <= job.max_retries:
        try:
            return job.task()
        except Exception as e:
            job.retries += 1
            if job.retries > job.max_retries:
                print(f"Job {job.id} failed after {job.max_retries} retries.")
                raise e
            
            delay = calculate_backoff(job.retries)
            print(f"Job {job.id} failed. Retrying in {delay:.2f}s...")
            time.sleep(delay)
```

### 3. `queue/priority.py`
 Implementation of the Priority Queue using a heap.

```python
import heapq
from typing import List
from .core import Job

class PriorityQueue:
    """A priority-based queue where lower numbers = higher priority."""
    def __init__(self):
        self._queue: List[tuple[int, Job]] = []

    def push(self, job: Job):
        # We use a tuple (priority, job) so heapq sorts by priority
        heapq.heappush(self._queue, (job.priority, job))

    def pop(self) -> Job:
        if not self._queue:
            raise IndexError("Priority queue is empty")
        _, job = heapq.heappop(self._queue)
        return job

    def __len__(self):
        return len(self._queue)
```

### Key Improvements Made:

1.  **Namespace Management**: By using `from .core import Job` (relative imports), the package is self-contained. If you move the `queue/` folder anywhere in your project, it won't break.
2.  **Complexity Reduction**: 
    *   `JobQueue` is now simple FIFO logic.
    *   `PriorityQueue` is isolated logic for `heapq`.
    *   `retry` logic is no longer entangled with the queue storage logic.
3.  **Type Hinting**: Added type hints (`Callable`, `List`, etc.) to ensure better IDE support and fewer runtime bugs.
4.  **Public API**: The `__init__.py` file ensures that users don't have to know the internal file structure (e.g., they don't need to import from `.core`, they just import from `queue`).
