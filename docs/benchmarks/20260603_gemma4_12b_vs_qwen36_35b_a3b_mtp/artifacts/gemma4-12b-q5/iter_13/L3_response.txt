    *   Requirements:
        1.  `add_job(name, data, priority=0)`: Add a job with a priority level (0, 1, 2).
        2.  Process higher priority first (Critical=2 > High=1 > Normal=0).
        3.  Same priority = FIFO order.
        4.  `get_next_job() -> tuple[str, dict] | None`: Get and remove the highest priority job.
    *   Constraint: Write only Python code, no explanations.

    *   Standard way to handle priority queues in Python is `heapq`.
    *   However, `heapq` is a min-heap. Since higher numbers mean higher priority (2 is highest), we can store priority as negative values or use a custom comparison.
    *   Requirement 3 (FIFO for same priority) is crucial. `heapq` handles tuples by comparing elements index by index. To ensure FIFO, we need a tie-breaker (like a counter).
    *   Data structure for a job: `(priority, sequence_number, name, data)`.
    *   To make it a max-priority queue using a min-heap, the priority should be negated (e.g., -2, -1, 0).

    *   `JobQueue` class.
    *   `__init__`: Initialize a list (heap) and a counter.
    *   `add_job(name, data, priority=0)`: Push `(-priority, counter, name, data)` into the heap.
    *   `get_next_job()`: Pop from the heap and return `(name, data)`.

    ```python
    import heapq
    from typing import Tuple, Dict, Optional

    class JobQueue:
        def __init__(self):
            self.queue = []
            self.counter = 0

        def add_job(self, name: str, data: Dict, priority: int = 0):

            # We use -priority.
            # We use self.counter to ensure FIFO for same priorities.
            heapq.heappush(self.queue, (-priority, self.counter, name, data))
            self.counter += 1

        def get_next_job(self) -> Optional[Tuple[str, Dict]]:
            if not self.queue:
                return None
            priority, count, name, data = heapq.heappop(self.queue)
            return (name, data)
    ```
