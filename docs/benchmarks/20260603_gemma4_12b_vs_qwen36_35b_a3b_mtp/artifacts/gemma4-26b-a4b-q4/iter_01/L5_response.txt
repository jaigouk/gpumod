### 1. `queue/core.py`
**Responsibility:** Defines the data models and the base queue logic.

```python
from dataclasses import dataclass, field
from typing import Any, List

@dataclass(order=True)
class Job:
    """Represents a unit of work."""
    priority: int
    data: Any = field(compare=False)

class JobQueue:
    """A basic FIFO (First-In-First-Out) job queue."""
    def __init__(self):
        self._jobs: List[Job] = []

    def push(self, job: Job) -> None:
        self._jobs.append(job)

    def pop(self) -> Job:
        if self.is_empty():
            raise IndexError("pop from empty queue")
        return self._jobs.pop(0)

    def is_empty(self) -> bool:
        return len(self._jobs) == 0

    def __len__(self) -> int:
        return len(self._jobs)
```

### 2. `queue/priority.py`
**Responsibility:** Specialized queue implementation using a heap. It inherits from the core logic but overrides the storage mechanism.

```python
import heapq
from .core import JobQueue, Job

class PriorityQueue(JobQueue):
    """A queue that retrieves jobs based on priority using a min-heap."""
    def __init__(self):
        # We initialize an empty list instead of the default list in JobQueue
        self._jobs = []

    def push(self, job: Job) -> None:
        heapq.heappush(self._jobs, job)

    def pop(self) -> Job:
        if self.is_empty():
            raise IndexError("pop from empty priority queue")
        return heapq.heappop(self._jobs)

    def is_empty(self) -> bool:
        return len(self._jobs) == 0

    def __len__(self) -> int:
        return len(self._jobs)
```

### 3. `queue/retry.py`
**Responsibility:** Contains the execution logic and error handling (Exponential Backoff).

```python
import time
from typing import Callable
from .core import Job

def process_with_retry(job: Job, func: Callable, retries: int = 3) -> Any:
    """
    Executes a function with a job's data, implementing exponential backoff.
    """
    attempt = 0
    while attempt < retries:
        try:
            return func(job.data)
        except Exception as e:
            attempt += 1
            if attempt >= retries:
                print(f"Job failed after {retries} attempts.")
                raise e
            
            wait_time = 2 ** attempt
            print(f"Attempt {attempt} failed. Retrying in {wait_time}s...")
            time.sleep(wait_time)
```

1.  **Circular Dependency Prevention:** `retry.py` and `priority.py` both import from `core.py`, but `core.py` remains "leaf-level" (it imports nothing from the other two).

3.  **Single Responsibility:** 
    *   If you want to change how a `Job` is structured, you only touch `core.py`.
    *   If you want to change the backoff algorithm, you only touch `retry.py`.
    *   If you want to add a `DatabaseQueue`, you simply add `database.py`.
