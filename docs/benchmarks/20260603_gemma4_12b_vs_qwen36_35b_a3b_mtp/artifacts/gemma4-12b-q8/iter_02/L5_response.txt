Here is the refactored package structure.

### 1. `queue/core.py`
*Responsibility: Define the data models and basic types.*

```python
from dataclasses import dataclass, field
from typing import Any
from enum import IntEnum

class Priority(IntEnum):
    HIGH = 1
    MEDIUM = 2
    LOW = 3

@dataclass(order=False)
class Job:
    payload: Any
    priority: Priority = Priority.MEDIUM
    job_id: str = field(default="unknown")
    retries: int = 0
    max_retries: int = 3

    def __lt__(self, other: "Job") -> bool:
        # Necessary for heapq to work in PriorityQueue
        if self.priority != other.priority:
            return self.priority < other.priority
        return self.job_id < other.job_id
```

### 2. `queue/priority.py`
*Responsibility: Logic for ordered storage.*

```python
import heapq
from typing import List
from .core import Job

class PriorityQueue:
    def __init__(self):
        self._queue: List[Job] = []

    def push(self, job: Job) -> None:
        """Adds a job to the queue based on priority."""
        heapq.heappush(self._queue, job)

    def pop(self) -> Job:
        """Removes and returns the highest priority job."""
        if not self._queue:
            raise IndexError("Pop from empty queue")
        return heapq.heappop(self._queue)

    def __len__(self) -> int:
        return len(self._queue)

    def is_empty(self) -> bool:
        return len(self._queue) == 0
```

### 3. `queue/retry.py`
*Responsibility: Execution logic and error handling.*

```python
import time
import random
from typing import Callable
from .core import Job

def process_with_retry(job: Job, action: Callable[[Any], Any]) -> Any:
    """
    Executes a function with exponential backoff.
    Formula: (2 ^ attempt) + jitter
    """
    attempt = 0
    while True:
        try:
            return action(job.payload)
        except Exception as e:
            attempt += 1
            if attempt > job.max_retries:
                print(f"Job {job.job_id} failed after {attempt} retries.")
                raise e
            
            wait_time = (2 ** attempt) + random.random()
            print(f"Retry {attempt}/{job.max_retries} for {job.job_id} in {wait_time:.2f}s...")
            time.sleep(wait_time)
```

### Key Improvements Made:

1.  **Separation of Concerns**: 
    *   If you want to change how the Priority Queue works (e.g., moving from `heapq` to a Redis backend), you only touch `priority.py`.
    *   If you want to change the backoff algorithm (e.g., linear instead of exponential), you only touch `retry.py`.
2.  **Type Safety**: Included type hints (`Job`, `Callable`) to improve IDE autocompletion and catch bugs early.
3.  **Complexity Reduction**: By using `dataclasses` in `core.py`, we reduced boilerplate code significantly.
4.  **Encapsulation**: The `__init__.py` file ensures that users of your library don't need to know the internal file structure; they can simply do:
    ```python

    ```
