*   Goal: Implement priority-based job scheduling.
    *   Core requirements:
        1.  `add_job` needs an optional `priority` parameter (default=0).
        2.  Priority order: Critical (2) > High (1) > Normal (0).
        3.  Tie-breaking: FIFO (First-In, First-Out) for same priority.
        4.  `get_next_job()`: Returns the highest priority job.
    *   Data Structure choice: A Priority Queue (Heap) is the standard way to handle priorities. Since Python's `heapq` is a min-heap, we need to store priority as a negative value (e.g., -2 for priority 2) to make it a max-heap, OR simply store priority such that higher numbers are popped first. Actually, `heapq` pops the smallest value. To make 2 higher than 1, we can use `-priority`.
    *   Tie-breaking: `heapq` keeps order if the second element of the tuple is unique. To maintain FIFO, we need an incrementing counter.

    *   `JobQueue` class.
    *   `self.jobs`: A list to store tuples `(-priority, sequence_number, name, data)`.
    *   `self.counter`: An integer to track insertion order.

    *   `add_job(name, data, priority=0)`:
        *   Increment `self.counter`.
        *   Push `(-priority, self.counter, name, data)` to heap.
    *   `get_next_job()`:
        *   Pop from heap.
        *   Return `(name, data)`.

import heapq

class JobQueue:
    def __init__(self):
        self.heap = []
        self.counter = 0

    def add_job(self, name: str, data: dict, priority: int = 0):
        # We use -priority because heapq is a min-heap, but we want higher numbers first.
        # self.counter ensures FIFO order for items with the same priority.
        heapq.heappush(self.heap, (-priority, self.counter, name, data))
        self.counter += 1
