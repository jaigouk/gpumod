*   Goal: Implement priority-based job scheduling for a `JobQueue`.
    *   Requirements:
        1.  `add_job(name, data, priority=0)`: Add job with optional priority.
        2.  Priority order: 2 (Critical) > 1 (High) > 0 (Normal).
        3.  Tie-breaking: Same priority must be FIFO (First-In, First-Out).
        4.  `get_next_job() -> tuple[str, dict] | None`: Return the highest priority job.
    *   Constraints: Write only Python code.

    *   A simple list sorted every time is $O(N \log N)$ or $O(N)$ per operation.
    *   A priority queue (heap) is $O(\log N)$ for push/pop.
    *   Standard `heapq` in Python is a *min-heap*. The requirements say higher numbers (2) are higher priority, so we should store the priority as its negative value (`-priority`) to use `heapq` as a max-priority queue.
    *   To handle FIFO for equal priorities, we need a secondary key: an incrementing counter (sequence number).

    *   Class: `JobQueue`
    *   Attributes:
        *   `heap`: A list to be used with `heapq`.
        *   `counter`: An integer to track arrival order for tie-breaking.
    *   `add_job(name, data, priority=0)`:
        *   `heapq.heappush(self.heap, (-priority, self.counter, name, data))`
        *   `self.counter += 1`
    *   `get_next_job()`:
        *   If `self.heap` is empty, return `None`.
        *   `neg_prio, count, name, data = heapq.heappop(self.heap)`
        *   Return `(name, data)`.

    *   Requirement 1: `add_job` accepts `priority=0`.
    *   Requirement 2: Higher priority first. (Using `-priority` in a min-heap accomplishes this).

```python
import heapq

class JobQueue:
    def __init__(self):
        self._queue = []
        self._counter = 0

    def add_job(self, name: str, data: dict, priority: int = 0):
        # heapq is a min-heap. To make it a max-priority queue, 
        # we negate the priority.
        # We include self._counter to ensure FIFO for jobs with the same priority.
        heapq.heappush(self._queue, (-priority, self._counter, name, data))
        self._counter += 1

    def get_next_job(self) -> tuple[str, dict] | None:
        if not self._queue:
            return None
        
        _, _, name, data = heapq.heappop(self._queue)
        return name, data
```
