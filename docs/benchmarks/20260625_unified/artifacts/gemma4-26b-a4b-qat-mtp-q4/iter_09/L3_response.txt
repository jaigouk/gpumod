*   Goal: Implement a priority-based job scheduling system for a `JobQueue`.
    *   Requirements:
        1.  `add_job(name, data, priority=0)`: Add job with priority.
        2.  Priority rule: Higher priority value (e.g., 2) comes before lower priority value (e.g., 0).
        3.  Tie-breaker: Same priority $\rightarrow$ FIFO order.
        4.  `get_next_job() -> tuple[str, dict] | None`: Returns `(name, data)` of the highest priority job.
    *   Priority levels: 0 (Normal), 1 (High), 2 (Critical).

    *   A priority queue is the ideal data structure.
    *   Python's `heapq` provides a min-heap.
    *   To make it a max-priority queue using a min-heap, we can negate the priority.
    *   To handle the FIFO requirement for identical priorities, we need a tie-breaker. A counter (sequence number) that increments every time a job is added is the standard way to ensure FIFO for equal priorities in a heap.

    *   `import heapq`
    *   `import itertools` (to get an infinite counter).

    ```python
    import heapq
    from itertools import count

    class JobQueue:
        def __init__(self):
            self._queue = []
            self._counter = count()

        def add_job(self, name: str, data: dict, priority: int = 0):
            # heapq is a min-heap.
            # We want higher priority first, so we use -priority.
            # We want FIFO for same priority, so we use the counter.
            # Tuple order: (-priority, sequence_number, name, data)
            heapq.heappush(self._queue, (-priority, next(self._counter), name, data))

        def get_next_job(self) -> tuple[str, dict] | None:
            if not self._queue:
                return None
            _, _, name, data = heapq.heappop(self._queue)
            return name, data
    ```
