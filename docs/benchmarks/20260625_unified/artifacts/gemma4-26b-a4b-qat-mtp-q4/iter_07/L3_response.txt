*   Goal: Implement priority-based job scheduling for a queue.
    *   Requirement 1: Modify `add_job(name, data, priority=0)`.
    *   Requirement 2: Higher priority $\rightarrow$ processed first.
    *   Requirement 3: Same priority $\rightarrow$ FIFO (First-In-First-Out).
    *   Requirement 4: `get_next_job() -> tuple[str, dict] | None`.
    *   Priority levels: 0 (Normal), 1 (High), 2 (Critical).

    *   Standard `queue.Queue` doesn't support priority.
    *   `heapq` (Priority Queue) is the standard way to handle priority in Python.
    *   *Problem with `heapq`:* `heapq` is a min-heap (lowest value first). The requirement says higher priority (2) comes before lower priority (0). So I need to store priority as `-priority` in the heap.
    *   *Problem with `heapq` and FIFO:* If two items have the same priority, `heapq` compares the next element in the tuple. If that next element is the job data, it might crash or behave incorrectly if the data isn't comparable. To maintain FIFO, I need a secondary sort key: a counter/sequence number.

    *   `self.heap`: A list to store `(-priority, sequence_number, name, data)`.
    *   `self.count`: An integer counter to ensure FIFO for equal priorities.

    *   `add_job(self, name, data, priority=0)`:
        *   `self.count += 1`

        *   `return (name, data)`

```python
import heapq

class JobQueue:
    def __init__(self):
        self._heap = []
        self._count = 0

    def add_job(self, name: str, data: dict, priority: int = 0):
        # We use -priority because heapq is a min-heap, 
        # and we want higher numbers to come out first.
        # self._count ensures FIFO order for jobs with the same priority.
        heapq.heappush(self._heap, (-priority, self._count, name, data))
        self._count += 1

    def get_next_job(self) -> tuple[str, dict] | None:
        if not self._heap:
            return None
        
        # Pop the item with the lowest value (which is the highest priority due to negation)
        _, _, name, data = heapq.heappop(self._heap)
        return name, data
```
