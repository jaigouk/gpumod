*   **Data Structure Choice:** A standard list or dictionary won't naturally handle priority and FIFO simultaneously easily.
    *   A list of lists/queues (one per priority level) would satisfy FIFO within a level but requires iteration over levels when fetching the next job.
    *   A heap (priority queue) is excellent for priority, but standard Python heaps are optimized for finding the maximum/minimum element, not strictly preserving FIFO order *within* equal priority levels automatically when added sequentially.
    *   *Refined approach:* We can use a dictionary mapping priority levels (0, 1, 2) to simple queues (lists). This is often clearer and easier to implement the specific requirement of FIFO within priority tiers.

*   **Implementation Details:**
    *   `JobQueue` class.
    *   `self.jobs` will be a dictionary where keys are priorities and values are lists (queues) of jobs.
    *   The key iteration must happen from highest priority (2) down to lowest (0).

class JobQueue:
    def __init__(self):
        # Dictionary mapping priority level (int) to a list (queue) of jobs.
        # Jobs stored as tuples: (job_name, metadata)
        self.jobs = {0: [], 1: [], 2: []}

    def add_job(self, job_name: str, metadata: dict = None, priority: int = 0):
        """
        Adds a job to the queue with the specified priority.
        Priority levels: 2 (Critical) > 1 (High) > 0 (Normal)
        """
        priority = int(priority)
        if priority not in self.jobs:
            # Ensure all three levels exist, although 0, 1, 2 are expected inputs
            self.jobs[priority] = []
        
        job_data = (job_name, metadata if metadata is not None else {})
        self.jobs[priority].append(job_data)

    def get_next_job(self) -> tuple[str, dict] | None:
        """
        Retrieves the highest priority job. 
        Priorities are checked in descending order (2, 1, 0).
        """
        # Iterate through priorities from highest (2) to lowest (0)
        for p in sorted(self.jobs.keys(), reverse=True):
            if self.jobs[p]:
                # Retrieve the job from the front of the queue (FIFO)
                job_name, metadata = self.jobs[p].pop(0)
                return job_name, metadata
        
        # If no jobs are found in any queue
        return None
