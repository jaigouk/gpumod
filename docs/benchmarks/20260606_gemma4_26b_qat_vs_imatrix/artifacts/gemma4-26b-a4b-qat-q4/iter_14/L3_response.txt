*   Goal: Implement priority-based job scheduling for a queue.
    *   Requirements:
        1.  `add_job(name, metadata, priority=0)`: Add job with optional priority.
        2.  Higher priority value = Higher priority.
        3.  Same priority = FIFO (First-In, First-Out).
        4.  `get_next_job() -> tuple[str, dict] | None`: Get the highest priority job.
    *   Priority levels: 0 (Normal), 1 (High), 2 (Critical).
    *   Output: Only Python code.

    *   A simple `list` and sorting every time? Inefficient ($O(N \log N)$ per retrieval).
    *   A `heapq` (binary heap)? Very efficient for priority ($O(\log N)$ insertion/removal).
    *   However, `heapq` in Python is a min-heap. Since higher priority values mean higher priority, I need to store the priority as a negative value to make it a max-heap behavior, OR use a tuple structure that handles the priority first.
    *   FIFO requirement for same priority: To maintain FIFO, a secondary sort key is needed (a counter/timestamp).

    *   Store elements in a list `self.queue`.
    *   `heapq.heappush(self.queue, (-priority, entry_count, job_name, job_metadata))`
    *   `entry_count` ensures that if priorities are equal, the one with the smaller `entry_count` (inserted earlier) comes first.
    *   `get_next_job` will use `heapq.heappop`.

    *   `__init__`: Initialize `self.queue = []` and `self.counter = 0`.
    *   `add_job(self, name, metadata, priority=0)`:
        *   `self.counter += 1`
        *   `heapq.heappush(self.queue, (-priority, self.counter, name, metadata))`
    *   `get_next_job(self)`:
        *   If empty, return `None`.
        *   `p, c, name, meta = heapq.heappop(self.queue)`
        *   Return `(name, meta)`.

    *   `add_job("normal", {"type": "normal"}, priority=0)` -> `heapq.push((-0, 1, "normal", {...}))`
    *   `add_job("critical", {"type": "critical"}, priority=2)` -> `heapq.push((-2, 2, "critical", {...}))`
    *   `add_job("high", {"type": "high"}, priority=1)` -> `heapq.push((-1, 3, "high", {...}))`
    *   Heap state (logic-wise): `[(-2, 2, "critical", ...), (-1, 3, "high", ...), (0, 1, "normal", ...)]`
    *   `pop()` -> `(-2, 2, "critical", ...)` -> returns `("critical", {"type": "critical"})`. Correct.

    *   If priorities are equal:
        *   Job A: priority 1, counter 1. Tuple: `(-1, 1, ...)`
        *   Job B: priority 1, counter 2. Tuple: `(-1, 2, ...)`
        *   Min-heap pops `(-1, 1)` before `(-1, 2)`. Correct (FIFO).

    *   Class `JobQueue`

```python
import heapq

class JobQueue:
    def __init__(self):
        self._queue = []
        self._counter = 0

    def add_job(self, name: str, metadata: dict, priority: int = 0):
        # We use -priority because heapq is a min-heap, but we want a max-priority queue.
        # self._counter ensures FIFO order for jobs with the same priority.
        heapq.heappush(self._queue, (-priority, self._counter, name, metadata))
        self._counter += 1

    def get_next_job(self) -> tuple[str, dict] | None:
        if not self._queue:
            return None
        
        _, _, name, metadata = heapq.heappop(self._queue)
        return name, metadata
```
