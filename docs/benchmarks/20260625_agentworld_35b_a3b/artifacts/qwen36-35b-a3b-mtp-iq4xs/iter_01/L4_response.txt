The race condition occurs because multiple threads can check for a job's existence, process it, and write results simultaneously, leading to data corruption or `KeyError` exceptions during deletion.

1.  **Adding a job**: Must be atomic.
2.  **Processing a job**: The check for existence, retrieval of data, and removal of the job from the queue must happen atomically to prevent double processing.
3.  **Writing results**: Must be atomic.

        self.jobs = {}
        self.results = {}
        # Initialize a lock to protect shared state

        with self.lock:
            self.jobs[job_id] = data

    def process_job(self, job_id, processor):

        # This prevents multiple threads from processing the same job simultaneously
