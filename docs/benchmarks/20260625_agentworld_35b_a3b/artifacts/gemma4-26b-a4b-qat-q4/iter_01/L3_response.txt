*   Goal: Implement priority-based job scheduling for a job queue.
    *   Requirements:
        1. `add_job(name, data, priority=0)`: Store jobs with priority.
        2. Priority logic: Higher priority first (2 > 1 > 0).
        3. Stability: Same priority = FIFO (First In, First Out).
        4. `get_next_job() -> tuple[str, dict] | None`: Return highest priority job.

    *   To handle priority + FIFO efficiently:
        *   A Heap (`heapq` in Python) is the standard for priority queues.
        *   `heapq` implements a min-heap (smallest value first).
        *   Since we want higher priority first, we can store priority as a negative number (e.g., priority 2 becomes -2).
        *   To maintain FIFO for same priorities, we need a tie-breaker. A common trick is using an incrementing counter (sequence number).
    *   The item stored in the heap: `(-priority, sequence_number, name, data)`.

    *   `__init__`: Initialize the heap and a counter.
    *   `add_job(name, data, priority=0)`:
        *   `self.counter += 1`
        *   `heapq.heappush(self.heap, (-priority, self.counter, name, data))`
    *   `get_next_job()`:
        *   If heap is empty, return `None`.
        *   `neg_prio, seq, name, data = heapq.heappop(self.heap)`
        *   Return `(name, data)`.

    import heapq

    class JobQueue:
        def __init__(self):
            self._heap = []
            self._counter = 0

        def add_job(self, name: str, data: dict, priority: int = 0) -> None:
            # Use -priority because heapq is a min-heap, but we want higher priority first.
            # Use self._counter to ensure FIFO for jobs with the same priority.
            heapq.heappush(self._heap, (-priority, self._counter, name, data))
            self._counter += 1

        def get_next_job(self) -> tuple[str, dict] | None:
            if not self._heap:
                return None
            _, _, name, data = heapq.heappop(self._heap)
            return name, data
