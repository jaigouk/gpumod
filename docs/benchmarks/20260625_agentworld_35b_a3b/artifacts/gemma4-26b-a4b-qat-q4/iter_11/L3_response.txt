*   Goal: Implement priority-based job scheduling in a `JobQueue` class.
    *   Requirements:
        1.  `add_job(name, data, priority=0)`: Add job with priority.
        2.  Higher priority first (2 > 1 > 0).
        3.  Same priority = FIFO (First In First Out).
        4.  `get_next_job() -> tuple[str, dict] | None`: Get and remove the highest priority job.

    *   A standard way to implement a priority queue in Python is using the `heapq` module.
    *   `heapq` is a min-heap. Since we want higher priority numbers to come first, we should store the priority as its negative (e.g., priority 2 becomes -2).
    *   To maintain FIFO for equal priorities, we can use a counter (sequence number) as the second element in the tuple stored in the heap. This way, if priorities are equal, the one with the smaller sequence number (the one added earlier) is popped first.

    *   `__init__`: Initialize an empty heap and a counter.
    *   `add_job(name, data, priority=0)`:
        *   Increment counter.
        *   Push `(-priority, counter, name, data)` into the heap.
    *   `get_next_job()`:
        *   If heap is empty, return `None`.
        *   Pop from heap.
        *   Return `(name, data)`.

    *   `priority`: 0 (normal), 1 (high), 2 (critical).
    *   Higher number = higher priority.
    *   Min-heap stores `(-priority, counter, ...)`.
    *   Example walk-through:
        1. `add_job("n", {}, 0)` -> heap: `[(0, 0, "n", {})]`
        2. `add_job("c", {}, 2)` -> heap: `[(-2, 1, "c", {}), (0, 0, "n", {})]`
        3. `add_job("h", {}, 1)` -> heap: `[(-2, 1, "c", {}), (0, 0, "n", {}), (-1, 2, "h", {})]` (actual heap structure varies, but order is correct).
    *   Pop:
        - `-2` is smallest. Returns `("c", {})`.
        - `-1` is next smallest. Returns `("h", {})`.
        - `0` is next. Returns `("n", {})`.

    ```python
    import heapq

    class JobQueue:
        def __init__(self):
            self._queue = []
            self._counter = 0

        def add_job(self, name: str, data: dict, priority: int = 0):
            # Use -priority for max-heap behavior with heapq (min-heap)
            # Use self._counter to ensure FIFO for same priority
            heapq.heappush(self._queue, (-priority, self._counter, name, data))
            self._counter += 1

        def get_next_job(self) -> tuple[str, dict] | None:
            if not self._queue:
                return None
            _, _, name, data = heapq.heappop(self._queue)
            return name, data
    ```

```python
import heapq

class JobQueue:
    def __init__(self):
        self._queue = []
        self._counter = 0

    def add_job(self, name: str, data: dict, priority: int = 0):
        # We use -priority because heapq is a min-heap, and we want higher numbers first.
        # We use self._counter to ensure FIFO order for jobs with the same priority.
        heapq.heappush(self._queue, (-priority, self._counter, name, data))
        self._counter += 1

    def get_next_job(self) -> tuple[str, dict] | None:
        if not self._queue:
            return None
        
        # Pop the item with the lowest negative priority (highest actual priority)
        # and the lowest counter (oldest insertion)
        _, _, name, data = heapq.heappop(self._queue)
        return name, data
```
