**Key Changes:**
1.  **Added `self.lock`**: Initialized in `__init__`.
2.  **`add_job`**: Wrapped the dictionary assignment in a lock to prevent concurrent writes.

    *   Used `pop()` to remove the job from the queue immediately (claiming it) to prevent multiple threads from processing the same job.

    def __init__(self):
        self.jobs = {}
        self.results = {}
        # 1. Initialize a Lock to synchronize access to shared state
        self.lock = threading.Lock()

        with self.lock:
            self.jobs[job_id] = data
