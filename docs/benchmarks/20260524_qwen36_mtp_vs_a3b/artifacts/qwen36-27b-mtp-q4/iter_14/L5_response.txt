### Key Design Decisions:
1. **Single Responsibility**: 
   - `core.py` handles the domain model (`Job`) and basic FIFO operations.
   - `priority.py` isolates heap-based ordering logic.
   - `retry.py` encapsulates fault tolerance and backoff algorithms.
2. **Relative Imports**: All modules use `.` prefix for intra-package imports, ensuring they work correctly when installed or run as a package.
3. **Type Safety**: Added modern type hints (`deque[Job]`, `Optional[Job]`, `Callable`, etc.) for better IDE support and static analysis.
4. **Priority Queue Tie-Breaking**: Added a monotonic `_counter` to `PriorityQueue` to guarantee FIFO ordering when jobs share the same priority level (prevents heap comparison errors with uncomparable `Job` objects).
5. **Clean API**: `__init__.py` exposes only the public interface, allowing consumers to import directly from `queue` without worrying about internal module structure.
