### Key Design Decisions:
1. **Single Responsibility**: 
   - `core.py` handles data modeling and basic FIFO behavior
   - `priority.py` encapsulates heap-based ordering logic
   - `retry.py` isolates fault tolerance and backoff algorithms
2. **Consistent Interface**: Both `JobQueue` and `PriorityQueue` share identical public methods (`enqueue`, `dequeue`, `peek`, `is_empty`, `size`), making them interchangeable via dependency injection.
3. **Stable Priority Sorting**: `PriorityQueue` uses a monotonic counter alongside priority values to preserve insertion order when priorities are equal.
4. **Production-Ready Retry**: Exponential backoff caps at `max_delay`, tracks attempts against `job.max_retries`, updates job status, and logs appropriately.
5. **Clean Public API**: `__init__.py` re-exports only the intended public symbols via `__all__`, preventing accidental leakage of internal modules.
